Тема: Python — основы

Python — это высокоуровневый язык программирования общего назначения.
Создан Гвидо ван Россумом в 1991 году.

Основные типы данных:
- int (целые числа): 1, 2, 100
- float (дробные): 3.14, 0.5
- str (строки): "привет"
- list (списки): [1, 2, 3]
- dict (словари): {"ключ": "значение"}
- bool (логический): True, False

Условие:
if x > 0:
    print("положительное")
elif x < 0:
    print("отрицательное")
else:
    print("ноль")

Циклы:
for i in range(10):
    print(i)

while x > 0:
    x -= 1

Функции:
def add(a, b):
    return a + b

Установка библиотек: pip install <имя>
Запуск: python файл.py
