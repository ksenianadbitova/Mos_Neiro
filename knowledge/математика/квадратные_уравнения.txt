Тема: Квадратные уравнения

Квадратное уравнение — уравнение вида ax² + bx + c = 0, где a ≠ 0.

Дискриминант: D = b² − 4ac

Если D > 0 — два корня: x = (−b ± √D) / (2a)
Если D = 0 — один корень: x = −b / (2a)
Если D < 0 — нет действительных корней

Пример: x² − 5x + 6 = 0
a=1, b=−5, c=6
D = 25 − 24 = 1
x₁ = (5 + 1) / 2 = 3
x₂ = (5 − 1) / 2 = 2

Теорема Виета:
Сумма корней: x₁ + x₂ = −b/a
Произведение: x₁ · x₂ = c/a
